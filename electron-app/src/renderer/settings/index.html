What should Thread watch?

Thread runs in the background and groups new items into Threads. Pick what it's allowed to watch — you can change this anytime in Settings, and everything stays on this machine except the short excerpts sent to Claude for classification (never full file contents).

What's stored, what's sent
  • Stored locally only: every file path, screenshot filename, clipboard snippet, and Thread — in a SQLite database on this machine (never uploaded anywhere).
  • Sent to Anthropic (Claude): only the filename, a short excerpt (first ~300 characters of text content, never full files), and your existing Thread names/summaries — needed to decide where a new item belongs.
  • Never sent anywhere: full file contents, images themselves, or anything outside the excerpt described above.

This is a student/portfolio project, not a production tool — treat it accordingly if you share it.
